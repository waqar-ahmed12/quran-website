## What it teaches

**Twenty-nine surahs start with letters read by their names**: الٓمٓ is not "alam", it is "Alif, Laam, Meem". There are
fourteen combinations:

الٓمٓ · الٓمٓصٓ · الٓر · الٓمٓر · كٓهٰيٰعٓصٓ · طٰهٰ · طٰسٓمٓ · طٰسٓ · يٰسٓ · صٓ · حٰمٓ · حٰمٓ عٓسٓقٓ · قٓ · نٓ

**How they are read:** each letter by its name (the names Lesson 1 taught). **The wavy line holds the long vowel of a
three-letter name for six beats**, the longest (Lesson 20): "Laaaam, Meeeem". **A two-letter name** (haa, yaa, taa,
raa) has a normal long vowel, which Indo-Pak marks with a khari zabar. **Alif** has no long vowel in its name to hold.

## The two scripts

| | Madani | Indo-Pak |
|---|---|---|
| the long hold | the wavy line on the three-letter names | the same |
| two-letter names | no mark (كٓهيعٓصٓ) | **khari zabar** (كٓهٰيٰعٓصٓ) |
| a name that merges into the next | nothing (الٓمٓ) | **a shadda** where the meem of "laam" merges into "meem" (الٓمّٓ) |

**Indo-Pak again prints how it is said.** The per-script line explains the merge the Indo-Pak shadda shows.

## What is drilled

The fourteen combinations. **Name it**: a combination, and pick how it is read ("Alif Laam Meem" among "Alif Laam
Raa"…). The choices are the other combinations' readings. And **by ear** once recorded.

## Examples

The first word of each surah's first verse, fetched: 2:1, 7:1, 10:1, 13:1, 19:1, 20:1, 26:1, 27:1, 36:1, 38:1, 40:1, 42:1–2,
50:1, 68:1. The references are the full plan's to confirm. **The spellings are the fetched text.** Madani كٓهيعٓصٓ has no
standing mark, and the student reads the names anyway.

## What is out

The merges' finer rules (the noon of "seen" hidden before the meem of طٰسٓمٓ), which the recording carries; the
meaning (unknown, and the page says nothing).
