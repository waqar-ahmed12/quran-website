Free Qaida · for the teacher

Qaida recording script

Everything the Qaida needs read aloud, lesson by lesson. Each box is one clip. Read each sitting right to left, top to bottom, in the order of the numbers.

  1. Say each box once, then pause for two seconds before the next.
  2. If you make a mistake, say it again. The last one is kept.
  3. From Lesson 4 on, say the sound only: “ba”, not “baa zabar ba”. Do not name the marks.
  4. A quiet room, the phone a hand’s length away, the same place every time.
