Hero frames → WebP

Runs entirely in this browser tab — nothing is installed, nothing leaves your PC. It reads each PNG in a folder you pick, re-encodes it as WebP, and writes the .webp file next to it. The original PNGs are left alone, so nothing breaks until the site's code is switched over to the new files.

This browser doesn't support picking a folder to write into (showDirectoryPicker). Open this page in Opera GX or another Chromium browser instead.
